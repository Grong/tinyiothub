# 巡检

## 执行步骤

1. 检查离线设备：列出离线超过阈值的设备，判断是否可自动重连。
2. 扫描未处理的高优先级告警：按严重程度排序，给出处置建议。
3. 生成状态摘要：聚焦异常与离线设备，正常设备一行带过。

## 计划状态

- 加载本技能后，将 Todo 中本技能的占位项展开为下面的执行步骤；每项是具体动作。若 Todo 中还没有本技能项，先添加。当前步骤为 `in_progress`，其余步骤为 `pending`。
- 每完成一个步骤，立即再次调用 `todo_write`：将该步骤标记为 `completed`，并将下一步骤标记为 `in_progress`。不要等到最终回复才更新。
- 输出最终总结前再次调用 `todo_write`：完成项标记为 completed；确实被阻塞、无法完成的项保留 pending/in_progress，在最终回复说明阻塞原因，不得伪装完成。
- 没有异常或提前结束时也要更新已执行项，不得让计划停留在初始状态。

## 注意事项

- 涉及写设备（重连、下发命令、改属性）必须先获得审批，不得自动执行。
- 没有异常时简短说明即可，不要编造进度。
