# 视频巡检

对指定摄像头（或全部摄像头）抓拍当前画面，逐张分析安防风险。本技能只使用
`call_device` 的 `snapshot` 动作；不要用 `read_device` 取快照。

## 输入

- 摄像头 ID、区域或“全部摄像头”。未指定时，先用 `list_devices` 按名称/标签
  关键词（摄像、camera、视频）筛选；需要时用 `get_thing_tree` 确认区域。
- 本次巡检的重点项（可选）：火焰、烟雾、吸烟、打架、聚众、呼喊、
  消防通道占用、人员闯入、物品遗留、设备遮挡等。

## 执行步骤

1. **确定范围**：列出目标摄像头，记录 ID、名称、区域。优先覆盖出入口、
   仓库、车间、配电间、消防通道等关键点位。
2. **逐台抓拍**：调用
   `call_device(thingId="<摄像头ID>", action="snapshot")`。
   成功时工具结果包含 `snapshot.evidence.evidenceId` 和图片附件。
   - 没有图片/evidence：记录“画面不可用”，不猜测画面内容。
   - 不要调用 `read_device(sources=["snapshot"])`。
3. **逐张分析**：只根据画面中可见证据判断，不把推测写成事实。
   - **火焰**：明火、火光、燃烧物、异常橙色/红色高温区域。判为疑似或确认时
     标记为 critical，要求立即核实并联动消防/告警；单帧不能确定时写“疑似明火”。
   - **烟雾**：灰/黑/白烟、雾状遮挡、烟柱、能见度下降。与消防探测器、邻近
     摄像头交叉核对；烟雾 + 火焰或火灾告警按 critical 处理。
   - **吸烟**：人员手持香烟/电子烟、口鼻附近烟雾、烟头。只描述可见事实，
     不识别身份；注意与蒸汽、呼出白气、设备排烟区分。
   - **打架**：肢体冲突、挥拳/推搡、多人围堵、倒地、异常姿态。单帧只能写
     “疑似肢体冲突”，建议调取连续画面/视频确认。
   - **聚众**：超过正常作业密度的人员聚集、通道被堵、围观。记录人数区间、
     位置和是否影响通行；不要把正常班组作业误报为聚众。
   - **呼喊**：**静态截图无法可靠判断“呼喊”**。只有画面出现张口、手势激烈、
     多人对峙等弱信号时，写“疑似呼喊/争吵（弱信号）”；需要音频或连续视频
     才能确认。没有音频来源时明确写“截图中不可判定”，不得据此报警。
   - **消防通道占用**：货物、托盘、车辆、设备、杂物占用通道/安全出口，
     遮挡消防设施或疏散指示；结合地面标线和门体位置判断。
   - **其他**：人员闯入/越界、物品遗留、摄像头遮挡/偏移、积水、设备冒烟、
     未佩戴防护用品、门窗异常等。
4. **交叉核验**：对 critical/high 发现，使用 `query_events`、告警查询或
   邻近摄像头/传感器复核；不要把单帧、单摄像头结果当作确认结论。
5. **给出处置**：
   - 火焰/烟雾/人员受伤/消防通道完全堵死：立即上报并联动现场，不等待巡检结束。
   - 打架/聚众/闯入：通知安保核实，保留 evidence，必要时报警。
   - 吸烟/一般占用：记录并通知责任区域整改，复查。
   - 不确定：写“疑似/不可判定”，给出复核方式，不编造结论。
6. **汇总输出**：按摄像头逐条给出表格；没有异常的摄像头一行带过。

## 输出格式

| 摄像头 | 区域/时间 | 发现 | 严重度 | 证据 | 置信度 | 建议 |
|---|---|---|---|---|---|---|

- 严重度：`critical` / `high` / `medium` / `low` / `normal`。
- 证据必须带 `evidenceId`；没有图片时写“画面不可用”。
- 置信度用“高/中/低”，并说明限制（单帧、遮挡、夜间、分辨率）。
- 结尾单独列出：无法从截图判断的项（尤其是呼喊/声音）、需要人工复核的项、
  已上报的 critical/high 项。

## 边界与安全

- 不进行人脸识别、身份识别或人种/性别推断；只描述与安全相关的外观事实。
- 不把“疑似”写成“确认”，不虚构不存在的火焰、烟雾、人数或证据。
- 本技能只读；不要调用 `set_device`、`run_composite` 或其他写动作。
- 发现真实火情/人员危险时，优先上报和疏散，不以“继续巡检”为由延迟。
- 如果模型无法查看图片附件，明确说明“图片不可读”，不要根据文字猜测画面。
