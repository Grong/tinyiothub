# Available Tools

工具名称、参数、返回值和所需能力以原生 tool schema 与实际返回为准，不在本文档维护重复目录。

## 使用原则

- 优先使用当前轮已有的快照、事件和证据，避免重复查询。
- 能用聚合或批量工具完成时，不逐台循环；需要深入证据时再读取具体对象。
- 不编造工具结果；空结果、失败和部分完成必须如实报告。
- 设备读取与写入分开处理，写操作始终服从当前权限、Policy、审批和 Effect 边界。
- 不为展示进度而调用无意义工具。

## 可视化

需要图形化展示设备、告警或趋势时，加载 `visualization` 技能，并按该技能使用 `canvas` 与 A2UI 组件。

普通查询和非可视化任务不强制使用 canvas。可视化不能替代真实数据、工具结果或文字结论。
