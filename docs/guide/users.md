# 用户管理

用户管理系统负责账号、权限和认证管理。

## 用户角色

| 角色 | 权限 |
|------|------|
| 管理员 | 完全访问权限 |
| 操作员 | 物管理和告警处理 |
| 查看者 | 只读访问 |

## 用户操作

### 创建用户

1. 进入「用户管理」页面（仅管理员可见）
2. 点击「新建用户」
3. 填写用户信息：
   - 用户名
   - 密码
   - 角色（如 admin、operator）
   - 邮箱
4. 保存

### 修改密码

用户可自行修改密码：

1. 进入「系统设置」页面
2. 找到「修改密码」区域
3. 输入新密码并确认
4. 保存

### 重置密码

管理员可重置用户密码：

1. 在用户列表找到目标用户
2. 点击「编辑」，在「修改密码」中输入新密码
3. 保存后通知用户使用新密码登录

## 权限管理

### 角色权限

| 权限 | 管理员 | 操作员 | 查看者 |
|------|:------:|:------:|:------:|
| 物管理 | ✓ | ✓ | ✗ |
| 驱动管理 | ✓ | ✗ | ✗ |
| 告警管理 | ✓ | ✓ | ✗ |
| 用户管理 | ✓ | ✗ | ✗ |
| 系统配置 | ✓ | ✗ | ✗ |

## 会话管理

### 登录会话

- 默认有效期：3 小时
- 可在配置中修改（`[security.session]` 的 `timeout_secs`）
