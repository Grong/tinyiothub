# 物管理

物管理是 TinyIoTHub 的核心功能，用于管理所有接入的"物"（物理或虚拟设备在管理面的抽象）。

## 创建物

### 通过新建物向导

1. 登录管理后台
2. 进入「物列表」页面（/things）
3. 点击「新建物」按钮
4. 选择物模板（内置模板或从应用市场安装的模板）
5. 填写物信息：
   - 物名称（工作空间内唯一）
   - 选择驱动
   - 配置驱动参数
6. 点击保存

### 安装更多模板

1. 进入「应用市场」页面（/marketplace）
2. 浏览并安装需要的物模板
3. 安装后可在「新建物」向导中选用

## 物的状态

| 状态 | 说明 |
|------|------|
| 🟢 在线 | 物正常连接 |
| 🔴 离线 | 物断开连接 |
| 🟡 告警 | 物触发告警 |
| ⚪ 未知 | 状态未知 |

## 物操作

### 查看详情

点击物列表中的物，进入详情页，包含以下 Tab：
- 属性（实时数据与历史）
- 命令（对物下发动作）
- 事件
- 告警（告警规则管理）
- 知识（挂载的知识文档，LLM 自动生成的物摘要）

### 编辑物

支持在线编辑物的配置，修改后自动生效。

### 删除物

> ⚠️ 删除物会同时删除相关数据，请谨慎操作！

### 远程控制

根据驱动支持情况，可在详情页「命令」Tab 对物下发动作（命令），如：
- 参数读取
- 控制指令下发
- 固件更新

## 数据采集

物支持多种数据采集模式：

- **主动上报**: 设备主动推送数据
- **定时轮询**: 系统定时读取
- **事件触发**: 状态变化时采集
