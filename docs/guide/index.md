# 用户指南

欢迎使用 TinyIoTHub 用户指南。本章节将帮助你了解系统的各项功能。

## 目录

- [物管理](./devices) - 物的添加、配置和管理
- [驱动管理](./drivers) - 驱动程序的安装和配置
- [告警管理](./alarms) - 告警规则和通知设置
- [用户管理](./users) - 用户账号和权限管理

## 核心概念

### 物 (Thing)

物是 TinyIoTHub 管理面的核心实体，代表物理或虚拟的 IoT 设备。每个物具有：

- **唯一名称**: 名称在工作空间（Workspace）内唯一
- **物模板**: 创建物的蓝图，预定义驱动与配置
- **属性 / 事件 / 动作**: 物的第一类要素，详情页按 Tab 查看
- **状态**: 在线/离线/告警

### 驱动 (Driver)

驱动是设备与系统通信的桥梁。TinyIoTHub 支持：

- Modbus RTU/TCP
- ONVIF (视频监控)
- SNMP
- Ping
- 自定义驱动

### 告警 (Alarm)

告警系统实时监控物的数据，支持：

- 阈值告警
- 状态变化告警
- 离线告警
- 多通道通知（MQTT、邮件等）

### 物模板 (Thing Template)

物模板简化物的创建过程，预定义：

- 驱动类型
- 配置参数
- 数据点映射
- 告警规则

模板除内置外，还可从「应用市场」安装。

### AI 助手与自治运维

系统内置自然语言交互（「AI 助手」聊天）和自治运维 Thing Agent Loop：由事件、定时任务或指令触发，支持 off / diagnose / act 三态策略（默认 off），可自主执行操作并回读验证，全程审计。
