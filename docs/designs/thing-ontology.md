## Vision

### 10x Check
万物皆孪生：平台里每一个物理或逻辑实体（设备、车间、园区、产线）都是一个有完整定义的"物"——结构（属性/事件/动作）、实时状态、知识（文档+摘要）三位一体。Agent 不读注入的上下文，而是像人一样"查目录、看档案、读手册"地按需理解世界。知识图谱是 workspace 级的大一统幻觉；本体是 IoT 的原生世界观。

### 行业背书
Azure Digital Twins（DTDL 本体）、W3C WoT Thing Description、阿里云物模型 TSL——方向与产业标准同构。

## Brainstorming 阶段已确认的 10 条核心决策

1. 混合层级：结构在模板层，知识挂实例层
2. workspace 知识图谱完全废弃，数据丢弃
3. 资源全部下沉到物
4. Device 原地泛化为 Thing（devices + thing_type）
5. Agent 完全工具化，无 system prompt 注入
6. 动作=commands 平移；事件新增，走 event 管线，告警可订阅
7. 知识=文档挂载+LLM 摘要（2000 字符/文档，≤5 篇，≤500 字输出）
8. 全量改造：后端+前端+拆除一次到位
9. parent_id 管归属（单父树），tags 管切面
10. API 一刀切只留 /api/things
