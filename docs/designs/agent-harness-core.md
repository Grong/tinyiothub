## Vision

### 10x Check
从人工触发的一次性 Task 升级为持续发现、协调和验证工作的物联网 Agent。统一 WorkflowDefinition 支撑巡检、视频、协同和节能，新增场景主要增加配置而非代码，目标以约 2x 核心实现成本获得 10x 持续运行价值。

### Platonic Ideal
运维用一份声明描述目标、设备、证据和约束。Host 持续调度，Main Agent 跨任务协调，Subagent 在隔离上下文中执行。设备联锁与 e-stop 不被绕过，动作可恢复且不重复，过程有证据，主上下文可从持久事实重建。配置可 dry-run，调度健康可观察，压缩可验证，24h 行为有实测证据。

## Accepted Scope (added to this plan)
- 三份版本化配置模板，复用统一 schema、引用校验和实例化/版本测试；通用定义文件导入仍属 deferred X5。
- `mode=simulation` dry-run，固定配置与历史 snapshot；无设备 worker、Effect 硬阻断、结果显著标识。
- Supervisor 面板显示 scheduled wake、oldest pending、调度延迟、Main/Subagent、错误与幂等恢复。
- 压缩血缘显示、临时 canonical state/hash 比较、失败保留旧快照且零 dispatch。
- 24h 模拟设备/受控 provider soak、指标告警与故障注入；执行前不宣称通过。XD9=C 进一步限定本期只交 runbook，不实际执行 24h。
- 停机、禁用和时钟前跳期间的过期 cron 全部跳过并记 missed；event 按持久来源去重，缺口告警且不生成 Effect。
- 统一 commands 承载 steer/interrupt/queue，支持幂等、过期、父子 target 与恢复；interrupt 不取消在途 Effect，cancel 才级联 drain。
- 联合审查修正：不可变 workflow_revisions 保存在途定义，来源幂等键不含版本；simulation 与生产 wake/恢复/Main 协调隔离；压缩比较固定 seq 并 CAS 替换。
