# E1 值守中枢（Watch 引擎 + LiveState）Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** 落地 E1a+b——watch 引擎（条件注册/评估/命中唤醒）+ LiveState（实时态+health/zone 摘要）+ scheduler 合并窗废除与同键限速器 + 账本与 watch 规则持久化。

**Architecture:** 评估器在 crates/runtime（纯逻辑零 sqlx，持久化走 ports）；唤醒适配器在 crates/agent（Trigger 接口）；持久源=watch_rules/hub_ledger 两张新表；内存评估态=易失投影，启动重织。详细设计见 spec：`docs/superpowers/specs/2026-10-20-e1-watch-hub-design.md`。

**Tech Stack:** Rust + tokio + sqlx(SQLite) + axum；测试 `cargo test -p <crate>`。

**前置条件（硬阻塞）：** ai-consolidation 分支收尾合入后再开始（本计划 Task 7/8 改 scheduler/manager，与其在途工作同批文件）。

## Global Constraints

- runtime crate 禁止直接 sqlx——持久化必须走 `crates/runtime/src/ports.rs` port trait（F3）
- `cache_and_publish` 不变量不动：device_cache 先写、EventBus 后发（data_server.rs）
- 合并窗废除是**显式行为变更**（eng D3/D4 裁定）：心跳/事件信号失去 30s 聚合，限速器是新的风暴防线
- 账本先不限速（F4 裁定），但日增行数超 100k 告警（观测兜底）
- 限额：每工作区活跃 watch ≤20；超时默认 600s 上限 3600s；同 watch 1s 内多次命中合并一次唤醒
- 限速器默认 N=3/分钟/键，配置键 `rate_limit_per_key_per_min` 写入 `workspaces.heartbeat_config` JSON（复用先例）
- 迁移文件名格式 `YYYYMMDDHHMMSS_<name>.sql`，纯 SQL（ddl-only 守卫）
- 命令：`cargo test -p tinyiothub_runtime` / `cargo test -p tinyiothub_agent` / `cargo test -p tinyiothub_db` / `cargo test -p tinyiothub-cloud`

use sqlx::SqlitePool;

#[derive(Debug, Clone, sqlx::FromRow)]
pub struct WatchRuleRow {
    pub id: String,
    pub workspace_id: String,
    pub kind: String,
    pub condition: String,
    pub persistent: i64,
    pub timeout_secs: i64,
    pub created_at: String,
}

pub async fn insert_rule(pool: &SqlitePool, row: &WatchRuleRow) -> Result<(), sqlx::Error> {
    sqlx::query(
        "INSERT INTO watch_rules (id, workspace_id, kind, condition, persistent, timeout_secs, created_at)
         VALUES (?, ?, ?, ?, ?, ?, ?)",
    )
    .bind(&row.id)
    .bind(&row.workspace_id)
    .bind(&row.kind)
    .bind(&row.condition)
    .bind(row.persistent)
    .bind(row.timeout_secs)
    .bind(&row.created_at)
    .execute(pool)
    .await?;
    Ok(())
}

pub async fn list_rules(pool: &SqlitePool) -> Result<Vec<WatchRuleRow>, sqlx::Error> {
    sqlx::query_as("SELECT * FROM watch_rules").fetch_all(pool).await
}

pub async fn delete_rule(pool: &SqlitePool, workspace_id: &str, id: &str) -> Result<u64, sqlx::Error> {
    let r = sqlx::query("DELETE FROM watch_rules WHERE workspace_id = ? AND id = ?")
        .bind(workspace_id)
        .bind(id)
        .execute(pool)
        .await?;
    Ok(r.rows_affected())
}

pub async fn append_ledger(
    pool: &SqlitePool,
    workspace_id: &str,
    ts: &str,
    kind: &str,
    thing_id: Option<&str>,
    payload: &str,
) -> Result<(), sqlx::Error> {
    sqlx::query("INSERT INTO hub_ledger (workspace_id, ts, kind, thing_id, payload) VALUES (?, ?, ?, ?, ?)")
        .bind(workspace_id)
        .bind(ts)
        .bind(kind)
        .bind(thing_id)
        .bind(payload)
        .execute(pool)
    .await?;
    Ok(())
}

```rust
//! E1 watch 条件词表 v1（spec 2026-10-20-e1 §2.3）：property 比较 / health 级别 / availability。
//! 词表版本化（P5）：序列化 payload 带 v=1。

use serde::{Deserialize, Serialize};

#[derive(Debug, Clone, Copy, PartialEq, Eq, Serialize, Deserialize)]
#[serde(rename_all = "lowercase")]
pub enum CompareOp { Lt, Gt, Eq, Ne }

#[derive(Debug, Clone, Copy, PartialEq, Eq, Serialize, Deserialize)]
#[serde(rename_all = "lowercase")]
pub enum HealthLevel { Attention, Bad }

#[derive(Debug, Clone, PartialEq, Serialize, Deserialize)]
#[serde(tag = "type", rename_all = "snake_case")]
pub enum WatchCondition {
    Property { thing_id: String, property: String, op: CompareOp, value: serde_json::Value },
    Health { thing_id: String, level: HealthLevel },
    Availability { thing_id: String, online: bool },
}

impl WatchCondition {
    /// 倒排索引键：条件挂在哪个物的哪个字段上。
    pub fn index_key(&self) -> (String, String) {
        match self {
            Self::Property { thing_id, property, .. } => (thing_id.clone(), property.clone()),
            Self::Health { thing_id, .. } => (thing_id.clone(), "__health".into()),
            Self::Availability { thing_id, .. } => (thing_id.clone(), "__availability".into()),
        }
    }

    /// 纯函数求值：字段新值是否使命题成立。类型不符/缺失一律不命中。
    pub fn matches(&self, thing_id: &str, field: &str, value: &serde_json::Value) -> bool {
        match self {
            Self::Property { thing_id: t, property, op, value: target } => {
                if t != thing_id || property != field { return false; }
                match (value.as_f64(), target.as_f64()) {
                    (Some(a), Some(b)) => match op {
                        CompareOp::Lt => a < b,
                        CompareOp::Gt => a > b,
                        CompareOp::Eq => a == b,
                        CompareOp::Ne => a != b,
                    },
                    _ => value == target && matches!(op, CompareOp::Eq)
                        || value != target && matches!(op, CompareOp::Ne),
                }
            }
            Self::Health { thing_id: t, level } => {
                t == thing_id && field == "__health"
                    && value.as_str() == Some(match level {
                        HealthLevel::Attention => "attention",
                        HealthLevel::Bad => "bad",
                    })
            }
            Self::Availability { thing_id: t, online } => {
                t == thing_id && field == "__availability" && value.as_bool() == Some(*online)
            }
        }
    }
}

#[derive(Debug, Clone)]
pub struct WatchRule {
    pub id: String,
    pub workspace_id: String,
    pub condition: WatchCondition,
    pub persistent: bool,
    pub timeout_secs: u32,
    pub created_at: String,
}

impl WatchRule {
    /// spec 限额：超时默认 600s、上限 3600s。
    pub const MAX_TIMEOUT_SECS: u32 = 3600;

    pub fn validate(&self) -> Result<(), String> {
        if self.timeout_secs == 0 || self.timeout_secs > Self::MAX_TIMEOUT_SECS {
            return Err(format!("timeout_secs must be 1..={}", Self::MAX_TIMEOUT_SECS));
        }
        Ok(())
    }
}
```

```rust
pub struct WatchTrigger {
    pub workspace_id: String,
    pub hit_rx: Arc<tokio::sync::Mutex<mpsc::Receiver<WatchHit>>>,
}

#[async_trait::async_trait]
impl Trigger for WatchTrigger {
    fn name(&self) -> &'static str { "watch" }

    async fn run(&self, tx: mpsc::Sender<WakeSignal>) -> anyhow::Result<()> {
        loop {
            let hit = {
                let mut rx = self.hit_rx.lock().await;
                rx.recv().await
            };
            let Some(hit) = hit else { return Ok(()); }; // channel 关闭=shutdown
            let signal = WakeSignal {
                workspace_id: hit.workspace_id.clone(),
                priority: Priority::Normal,
                dedup_key: Some(format!("watch:{}", hit.rule_id)),
                source: TriggerSource::Watch {
                    rule_id: hit.rule_id,
                    summary: hit.summary,
                    current_value: hit.current_value,
                    health: hit.health,
                    zone: hit.zone,
                },
            };
            if tx.send(signal).await.is_err() { return Ok(()); }
        }
    }
}
```
