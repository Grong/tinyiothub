# 2026-11-14

## 产品定位调整：AIoT 平台 → IoT agent harness

用户明确最新方向：TinyIoTHub 不是 AIoT 平台，而是 **IoT agent harness**。设备接入是底座，设备之上的 agent 运行环境才是产品本体。

### 定位结论
- 三层结构：应用（SKILL.md）/ Harness（Session Loop + Skill/Todo/Ask/Subagent + 安全层）/ 设备（协议 + 物本体）。价值在中间层。
- 三条护城河（通用 agent framework 无法复制）：
  1. Effect/Decision 单赢家 + unknown fence（设备动作不可重试）
  2. 事件唤醒 + 本体决策（不靠用户喂上下文）
  3. 回读验证 + 全量审计
- 叙述锚点：「Claude Code 给代码写 harness，TinyIoTHub 给设备写」。
- 对外口号：「让 AI 真正动手」/ "Give your agent hands."
- 双轨表述：技术场合用「IoT agent harness」，商务场合用「会让设备自己干活的智能体底座」。
